The problem

Your assistant can only keep secrets it never learned.

Companies are building internal assistants on HR files, support tickets and contracts. Those documents are full of personal data. Embed them as they are and the chatbot can quote an SSN or a medical detail to anyone who phrases the question well. Most ingestion pipelines have no step that checks for this, and existing tools are either enterprise-priced platforms or hosted APIs that a privacy-conscious company cannot send raw data to.

i

Raw text is embedded

Names, card numbers and diagnoses become vectors that can be retrieved verbatim.

ii

No gate before the index

Nothing sits between text extraction and the embedding model.

iii

Cleanup means a full rebuild

One leaked file forces teams to re-embed the whole knowledge base.

The pipeline

One checkpoint between extraction and embedding.

A document goes in. Sanitized text comes out. Nothing else reaches your embedder or vector store.

Detection

Layered, validated, and scored.

Pattern rules REGEX

Fast matching for SSNs, emails, phone numbers, IBANs and other structured identifiers.

Checksum validation LUHN

A card number is only flagged when it passes its checksum, which cuts false alarms.

NLP entity recognition NER

A small model, loaded once at startup, finds names, addresses, organizations and medical terms in free text.

Context scoring CONFIDENCE

Surrounding words raise or lower each score, so "SSN:" next to nine digits ranks above nine digits alone.

Decisions

Every entity gets a decision, not a guess.

A person decides in interactive mode. Policy rules decide in automated batch mode. Try each choice on the same sentence.

Deployment

Easy to try. Strict where it counts.

DEVELOPMENT

Fast to start

  • Docker Compose with normal internet access
  • Rules plus a small NLP model, about 100 to 300 MB of RAM
  • Hosted embedding API behind the same interface
  • Local Qdrant container
  • Synthetic data only
PRODUCTION

Private by design

  • Model weights bundled in the image, no runtime downloads
  • Zero outbound network calls while processing
  • Runs on Kubernetes, ECS or on-premise
  • Fully local, or sanitized text only to approved endpoints
  • Access-control metadata on every chunk
